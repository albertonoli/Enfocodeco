# Catálogo de productos

Una carpeta por producto, con el nombre como se lo llama en la tienda (sin tildes ni espacios):

```
productos/
  aplique-nordico/
    frente.jpg
    perfil.jpg
    ficha.md        ← medidas, material, terminación, lámpara, precio (opcional)
  colgante-campana-negro/
    ...
```

Así los agentes lo encuentran por nombre: "armá un lifestyle con el aplique nórdico".

**Consejos para las fotos:** fondo liso y contrastado, buena luz, producto completo y sin cortar,
la mayor resolución posible. Varias vistas (frente, perfil, encendido) ayudan a que las escenas salgan fieles.
